BioFormat Toolkit¶

Документация проекта BioFormat Toolkit — набора инструментов на Python для чтения и анализа биоинформатических файлов форматов FASTA, FASTQ, SAM и VCF.

Проект использует объектно-ориентированный подход. Для последовательной обработки записей применяются итераторы и генераторы, позволяющие работать с большими файлами без загрузки всех данных в память.

# BioFormat Toolkit
Набор инструментов на Python для чтения и анализа файлов в форматах FASTA, FASTQ, SAM и VCF.

## О проекте

**BioFormat Toolkit** — учебный командный проект на Python, предназначенный для работы с распространёнными форматами биоинформатических данных.

Программа разрабатывается с использованием объектно-ориентированного подхода. Для обработки больших файлов планируется использовать генераторы, позволяющие последовательно читать записи без необходимости загружать весь файл в оперативную память.

## Планируемая функциональность

### FASTA
- Чтение последовательностей.
- Подсчёт количества последовательностей.
- Вычисление средней длины последовательности.

### FASTQ
- Чтение последовательностей и соответствующих значений качества.
- Подсчёт количества последовательностей.
- Вычисление средней длины последовательности.
- Построение графиков:
  - Per base sequence quality;
  - Per base sequence content;
  - Sequence length distribution.

### SAM
- Чтение заголовков и записей выравнивания.
- Получение информации из групп заголовков, включая `@PG` и `@RG`.
- Подсчёт общего количества выравниваний.
- Подсчёт выравниваний по хромосомам с использованием pandas.
- Поиск выравниваний, пересекающих заданный геномный интервал.

### VCF
- Чтение заголовков и записей о геномных вариантах.
- Получение информации из групп заголовков.
- Подсчёт общего количества вариантов.
- Подсчёт вариантов по геномным регионам с использованием pandas.
- Получение вариантов из заданного геномного интервала.

## Архитектура

В основе проекта лежит иерархия классов для работы с различными форматами файлов.

Предварительная структура:

```text
Reader
├── SequenceReader
│   ├── FastaReader
│   └── FastqReader
│
└── GenomicDataReader
    ├── SamReader
    └── VcfReader
```

Окончательные интерфейсы классов и архитектурные решения будут описаны в [ARCHITECTURE.md](ARCHITECTURE.md).

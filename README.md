# BioFormat Toolkit

**BioFormat Toolkit** — учебный командный проект на Python для чтения и базового анализа биоинформатических файлов в форматах FASTA, FASTQ, SAM и VCF.

Проект разработан с использованием принципов объектно-ориентированного программирования (ООП). Его архитектура основана на иерархии классов, обеспечивающей единый подход к обработке различных форматов биологических данных.


📖 **[Документация проекта (GitHub Pages)](https://nnvrmind.github.io/bioformat_toolkit/)**

## Возможности

### FASTA

- Чтение нуклеотидных последовательностей из FASTA-файлов.
- Поддержка последовательностей, записанных на нескольких строках.
- Получение идентификаторов и длин последовательностей.
- Подсчёт общего количества последовательностей.
- Вычисление средней длины последовательностей.

### FASTQ

- Чтение нуклеотидных последовательностей и соответствующих строк качества.
- Подсчёт количества прочтений.
- Вычисление средней длины прочтений.
- Построение графиков:
  - **Per base sequence quality** — качество нуклеотидов по позициям.
  - **Per base sequence content** — нуклеотидный состав по позициям.
  - **Sequence length distribution** — распределение длин прочтений.

### SAM

- Чтение заголовков и записей выравнивания.
- Получение информации из выбранных групп заголовков.
- Подсчёт общего количества выравниваний.
- Подсчёт выравниваний по референсным последовательностям.
- Поиск выравниваний, пересекающих заданный геномный интервал.
- Представление статистических результатов в виде таблиц с использованием `pandas`.

### VCF

- Чтение метаданных и записей о генетических вариантах.
- Получение информации из выбранных групп заголовков.
- Подсчёт общего количества вариантов.
- Поиск вариантов в заданном геномном интервале.
- Получение статистики по выбранному региону.
- Представление результатов в виде таблиц с использованием `pandas`.

## Архитектура

В основе проекта лежит иерархия классов:

```text
Reader
├── SequenceReader
│   ├── FastaReader
│   └── FastqReader
│
└── GenomicDataReader
    ├── SamReader
    └── VcfReader
```

**Reader** — абстрактный базовый класс, определяющий общий интерфейс чтения файлов.

**SequenceReader** — промежуточный абстрактный класс для работы с последовательностями. Содержит общие методы подсчёта количества последовательностей и вычисления их средней длины.

**GenomicDataReader** — промежуточный класс для работы с геномными данными, включая заголовки и записи, связанные с референсными последовательностями и геномными координатами.

**FastaReader, FastqReader, SamReader и VcfReader** — специализированные классы, реализующие чтение и обработку соответствующих форматов.

Подробнее архитектура описана в [ARCHITECTURE.md](ARCHITECTURE.md).

## Установка

### Клонирование репозитория

```bash
git clone https://github.com/nnvrmind/bioformat_toolkit.git
cd bioformat_toolkit
```

### Установка зависимостей

Для работы проекта используются библиотеки `pandas`, `numpy` и `matplotlib`. Для запуска автоматических тестов необходим `pytest`.

При использовании Conda необходимые зависимости можно установить командой:

```bash
conda install pandas numpy matplotlib pytest
```

## Использование

Для демонстрации возможностей проекта предусмотрена программа `main.py`.

Общий синтаксис:

```bash
python main.py <format> <filepath>
```

Где:
- `format` — один из поддерживаемых форматов: `fasta`, `fastq`, `sam`, `vcf`.
- `filepath` — путь к соответствующему файлу.

### FASTA

```bash
python main.py fasta data/example.fasta
```

Программа выводит последовательности, их идентификаторы и длины, а также общее количество последовательностей и их среднюю длину.

Для длинных последовательностей отображаются только первые 100 символов.

### FASTQ

```bash
python main.py fastq data/example.fastq
```

Программа выводит информацию о первых 10 прочтениях, подсчитывает количество и среднюю длину последовательностей, а затем строит графики качества, нуклеотидного состава и распределения длин.

### SAM

```bash
python main.py sam data/example.sam
```

Программа позволяет:

1. Просмотреть заголовки SAM-файла.
2. Выбрать группу заголовков.
3. Получить количество выравниваний.
4. Просмотреть статистику по референсным последовательностям.
5. Указать референсную последовательность и геномный интервал.
6. Получить первые 10 найденных выравниваний.

### VCF

```bash
python main.py vcf data/example.vcf
```

Программа позволяет:

1. Просмотреть заголовки VCF-файла.
2. Выбрать группу метаданных.
3. Получить общее количество генетических вариантов.
4. Указать хромосому и геномный интервал.
5. Просмотреть первые 10 найденных вариантов.
6. Получить статистику по выбранному региону.

Для SAM и VCF названия референсных последовательностей необходимо вводить в соответствии с обозначениями в исходном файле, например `1` или `chr1`.

**Примечание:** папка `data/` предназначена для локальных входных файлов и исключена из отслеживания Git. Пользователь самостоятельно размещает в ней файлы для демонстрации. Небольшие данные для автоматических тестов хранятся отдельно в `tests/data/`.

## Тестирование

Для автоматического тестирования проекта используется **pytest**.

Тесты проверяют:
- Корректность чтения файлов поддерживаемых форматов.
- Работу методов анализа и вычисления статистики.
- Обработку некорректных входных данных.
- Соответствие полученных результатов ожидаемым значениям.

**Все реализованные тесты успешно проходят.**

Для запуска всех тестов из корневой директории проекта:

```bash
python -m pytest
```

Для запуска отдельного тестового модуля:

```bash
python -m pytest tests/test_fasta.py -v
```

Тестовые данные размещены в директории `tests/data/`.

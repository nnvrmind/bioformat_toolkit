class readers.sequence_reader.SequenceReader(filepath)[исходный код]¶

Базовые классы: Reader

Абстрактный промежуточный класс для чтения файлов с последовательностями.

Наследуется от Reader и добавляет общие для всех форматов последовательностей методы: подсчёт количества записей и вычисление средней длины.

FastqReader¶

class readers.fastq_reader.FastqReader(filepath)[исходный код]¶

Базовые классы: SequenceReader

Класс для чтения файлов формата FASTQ.

Наследуется от SequenceReader и возвращает записи FastqRecord.

Параметры:

filepath (str | Path) – Путь к FASTQ-файлу.

plot_per_base_quality()[исходный код]¶

Строит график среднего качества секвенирования по позициям.

Используется кодировка Phred+33.

Исключение:

ValueError – Если файл не содержит последовательностей или содержит символы качества вне диапазона Phred+33.

Тип результата:

None

plot_per_base_content()[исходный код]¶

Строит график содержания нуклеотидов по позициям.

Для каждой позиции вычисляет процент A, C, G и T среди всех последовательностей, содержащих эту позицию.

Исключение:

ValueError – Если FASTQ-файл не содержит последовательностей.

Тип результата:

None

plot_length_distribution()[исходный код]¶

Строит график распределения длин последовательностей.

Для каждой длины показывает количество прочтений такой длины.

Исключение:

ValueError – Если FASTQ-файл не содержит последовательностей.

Тип результата:

None

get_header_group(group)[исходный код]¶

Получает строки указанной группы метаданных VCF-файла.

Параметры:

fetch(chromosome, start, end)[исходный код]¶

Последовательно возвращает варианты, позиции которых входят в указанный геномный интервал.

Параметры:

  • chromosome (str) – Имя хромосомы.

  • start (int) – Начало интервала (1-based, включительно).

  • end (int) – Конец интервала (1-based, включительно).

Yields:

dict[str, str] – Варианты, позиции которых входят в указанный геномный интервал.

Исключение:

  • TypeError – Если имя хромосомы или координаты имеют некорректный тип.

  • ValueError – Если имя хромосомы пустое или границы интервала некорректны.

Тип результата:

Iterator[dict[str, str]]

count_by_region(chromosome, start, end)[исходный код]¶

Возвращает статистику количества вариантов в заданном геномном интервале.

Параметры:

  • chromosome (str) – Имя хромосомы.

  • start (int) – Начало интервала (1-based, включительно).

  • end (int) – Конец интервала (1-based, включительно).

Результат:

Таблица с колонками chromosome, start, end, count. count — количество вариантов в указанном интервале.

Тип результата:

pd.DataFrame

Исключение:

  • TypeError – Если имя хромосомы или координаты имеют некорректный тип.

  • ValueError – Если имя хромосомы пустое, границы интервала некорректны или VCF-файл имеет некорректную структуру.
